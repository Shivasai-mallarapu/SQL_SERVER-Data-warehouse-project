# SQL Server Data Warehouse Project
 
## Overview
This project focuses on building a data warehouse using SQL Server to organize data and support analytical reporting. It demonstrates a structured approach to data processing, data quality checks, and analytical data modeling.

## Project Objectives
- Organize data for analytical use.
- Structure data processing through warehouse layers.
- Create Gold-layer views for customer, product, and sales analysis.
- Implement SQL-based data quality checks.
- Maintain organized SQL scripts, datasets, documentation, and tests.

## Repository Structure
- `Docs/` — Project documentation.
- `datasets/` — Project datasets.
- `scripts/` — SQL scripts for warehouse development and transformations.
- `tests/` — SQL scripts for data quality checks and testing.

## Technologies
- Microsoft SQL Server
- T-SQL
- SQL-based data transformation and validation

## Key Work
- Customer, product, and sales Gold views.
- Silver-layer data quality checks.
- Structured SQL scripts for data warehouse development.

## How to Explore
1. Review the `Docs/` folder for project documentation.
2. Explore `datasets/` to understand the input data.
3. Review the SQL files in `scripts/`.
4. Explore `tests/` to understand the data quality checks.

## Learning Outcomes
This project provides practical experience in SQL development, data organization, data quality validation, and data warehousing concepts.
